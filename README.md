# Support Ticketing System

## Project Overview
A web-based IT Helpdesk Support Ticketing System developed for the Web & Cloud Application module assessment. It allows users to submit and manage support tickets while support agents handle and resolve reported issues.

## Features
- User registration and login
- Create, view, and close support tickets
- Support agent login
- Search open tickets
- Resolve and escalate tickets
- Track ticket statuses: Open, Resolved, and Closed

## Technologies Used
- PHP
- MySQL
- JavaScript
- Docker and Docker Compose
- HTML and CSS

## How to Run
1. Install Docker Desktop.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Start the application using:

   ```bash
   docker compose up -d --build
   ```

5. Open `http://localhost:8080` in your browser.
